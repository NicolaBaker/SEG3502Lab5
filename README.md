## Les étapes nécessaires pour installer et exécuter le projet

Groupe 23 Nicola Baker, 300360908 Maxime Malouf, 300238380

Cloner le projet dans le terminal : git clone https://github.com/NicolaBaker/SEG3502Lab5.git
Ensuite entrer dans le dossier du projet : cd employee-app
Vérifier que Node.js, npm et Angular CLI sont installés.
Installer les dépendances du projet dans le dossier employee-app : npm install
Démarrer le serveur : ng serve
Si ng serve ne fonctionne pas vous pouvez utiliser : npx ng serve
Ouvrir le projet dans le navigateur une fois le serveur démarré. Vous devriez voir une adresse comme : http://localhost:4200/
Vous pouvez ajouter un employé en remplissant les champs et en cliquant sur Save Employee. Ensuite, vous pouvez cliquer sur Employee List pour voir tous les employés enregistrés dans Firebase.
Pour arrêter le serveur, faites : Ctrl + C
